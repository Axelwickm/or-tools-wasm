# OR-Tools Benchmarking

The generated results below describe the recorded commit and runtime versions,
not necessarily the current worktree. They are performance measurements, not
a substitute for the fixture and site test suites.

Run the benchmark suite:

```sh
benchmarking/run.sh
```

This packs the local npm package, runs the Docker benchmarks, writes CSVs under `benchmarking/results/`, and refreshes this report. To rerender existing CSVs only:

```sh
python3 benchmarking/scripts/render_results.py
```

To benchmark an already-built release artifact instead of the local build:

```sh
BENCH_PACKAGE_TARBALL=/absolute/path/to/or-tools-wasm.tgz \
BENCH_GIT_SHA=<artifact-source-commit> benchmarking/run.sh
```
