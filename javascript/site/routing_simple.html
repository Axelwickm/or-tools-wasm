Simple routing

Problem: find the shortest route for one vehicle to visit every location and return to the depot.

  • One vehicle leaves the depot, visits each destination and returns.
  • The aim is to find a short route using straight-line travel distances.
  • Choose a scenario to add a driver break, traffic or a pickup and delivery.
  • After solving, the map and visit list show the planned route.
