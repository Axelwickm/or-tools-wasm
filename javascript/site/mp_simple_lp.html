MPSolver - frontend sample

Problem: solve one small linear model through MPSolver while switching between available LP and integer backends.

Show code 
import { MpModel, MPSolver } from 'or-tools-wasm/mp-solver';

const solver = MPSolver.createSolver('GLOP');
if (!solver) throw new Error('GLOP is unavailable');
solver.setNumThreads(4);

const x = solver.addNumVariable(0, 1, 'x');
const y = solver.addNumVariable(0, 1, 'y');
const c0 = solver.addConstraint(-solver.infinity(), 1);
c0.setCoefficient(x, 1);
c0.setCoefficient(y, 1);

const objective = solver.objective();
objective.setCoefficient(x, 2);
objective.setCoefficient(y, 1);
objective.setMaximization();

await solver.solveWithProto({ executor: 'worker',
  messageCallback: messages => messages.forEach(message => console.log(message)),
});
if (!await solver.verifySolution(1e-7, true, { executor: 'worker' })) {
  throw new Error('Solution verification failed');
}
console.log(x.solutionValue(), y.solutionValue());
const model = new MpModel('retained answers');
const retainedX = model.addNumVariable(0, 1, 'x');
model.objective().setCoefficient(retainedX, 2);
model.objective().setMaximization();
const session = model.incremental({
  solverType: MPSolver.GLOP_LINEAR_PROGRAMMING, executor: 'worker',
});
try {
  const first = await session.solve();
  retainedX.setUpperBound(0);
  const second = await session.solve();
  console.log(first.value(retainedX), second.value(retainedX)); // 1, 0
  console.log(second.solverVersion, second.iterations);
} finally {
  await session.close();
}
const conflict = new MpModel('conflicting limits');
const limit = conflict.addNumVariable(0, 10, 'x');
conflict.addConstraint(2, Infinity).setCoefficient(limit, 1);
conflict.addConstraint(-Infinity, 1).setCoefficient(limit, 1);
const iis = await conflict.computeIrreducibleInfeasibleSubset({
  executor: 'worker', timeLimitSeconds: 5,
});
console.log(iis.isInfeasible, iis.constraintIndices);

MPSolver routes one tiny linear model through selectable backends. GLOP, CLP, and GLPK_LP solve it as a continuous LP; SAT, GLPK, SCIP, CBC, BOP, and Knapsack solve the same model with integral variables.

Model

  • The model has two variables, one capacity constraint, and one linear objective.
  • The solver menu changes which MPSolver backend receives the model.
  • LP backends solve continuous variables; integer backends solve integral variables.
  • The result compares objective value, variable values, iterations, and branch-and-bound nodes.
  • Native solver messages appear in the log for supported backends.
  • SCIP can diagnose conflicting limits, returning the source constraints and bounds in its native infeasible subsystem.
  • Retained sessions solve twice on the same native solver, applying a bound change through native setters. GLPK server sessions are unavailable because its environment belongs to the creating job thread.
