PDLP — Import a model

Problem: import a linear or diagonal quadratic model and solve it with PDLP.

Show code 
import { Pdlp } from 'or-tools-wasm/pdlp';

const qp = await Pdlp.readQuadraticProgram(mpsText, {
  format: 'mps', includeNames: true, executor: 'worker',
});
const result = await Pdlp.solve(qp, { executor: 'worker', numThreads: 1 });
console.log(result.solveLog.terminationReason, result.primalSolution);
// Convert an objective evaluated without offset/scaling to original model units:
console.log(qp.applyObjectiveScalingAndOffset(-12)); // 17 for this example

Paste a model or choose a file. Switching formats loads the same sample in the selected text format. For binary protobuf models, choose a file.

Model

  • The sample maximizes 3x + 5 with 0 ≤ x ≤ 4 and a capacity constraint x ≤ 4.
  • The optimum is x = 4 with objective value 17 in every sample format.
  • PDLP solves continuous variables; enable integer relaxation to import integer models as continuous problems.
  • The result shows variable values, the objective, termination status, and iterations.
