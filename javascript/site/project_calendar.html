CP-SAT - Calendar Scheduling

Schedule project tasks around prerequisites, lunch and staff availability.

Show code

Each day has a column for each person. Shared tasks span their participants' columns. Drag a task to set a preferred time. Click Replan to calculate a schedule. To require an exact time, select the task and click Lock time below the calendar.

The initial draft places Integration during Bo's time off. Click Replan to resolve it.

Project brief

Model

Tasks cannot overlap for the same person and must follow their dependencies. Work stays within 09:00–17:00, excluding lunch (12:00–13:00) and Bo's Wednesday morning off. All tasks must finish by the deadline.

Moving an unlocked task changes its preferred time, not a requirement. Replan may move it again to satisfy the constraints. The objective is total deviation from preferred times, counting daytime hours only.
