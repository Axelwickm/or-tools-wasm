GLPK - simple linear program

Problem: choose values for two continuous variables that maximize profit while staying inside two linear resource limits.

Show code 
import { MPSolver } from 'or-tools-wasm/mp-solver';
const solver = MPSolver.createSolver('GLPK_LP');
if (!solver) throw new Error('GLPK_LP is unavailable');
solver.setNumThreads(4);

const x = solver.addNumVariable(0, solver.infinity(), 'x');
const y = solver.addNumVariable(0, solver.infinity(), 'y');
const c0 = solver.addConstraint(-solver.infinity(), 17.5);
c0.setCoefficient(x, 1);
c0.setCoefficient(y, 7);
const c1 = solver.addConstraint(-solver.infinity(), 3.5);
c1.setCoefficient(x, 1);
const objective = solver.objective();
objective.setCoefficient(x, 1);
objective.setCoefficient(y, 10);
objective.setMaximization();

await solver.solve({ executor: 'worker' });

The simple_lp_program.py model solved with the GLPK LP backend.

Model

  • The decision variables are continuous values for x and y.
  • The constraints limit the feasible region to a small polygon.
  • The objective maximizes a linear profit expression.
  • GLPK solves the LP and returns the best feasible corner.
